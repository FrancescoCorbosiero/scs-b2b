# Foto reali delle pagine pubbliche

Metti qui le foto per sostituire le illustrazioni di default, con questi nomi
(estensione a scelta tra jpg, jpeg, png, webp, avif, svg):

| File | Dove compare | Formato consigliato |
|---|---|---|
| `hero.jpg` | Sfondo delle intestazioni scure (home, come ordinare, spedizioni, richiedi accesso) | orizzontale, ≥ 1920×1080, soggetto scuro o scontrastato (sopra ci va testo bianco) |
| `cta.jpg` | Blocchi call-to-action con immagine (home e spedizioni) | 4:3 o quadrata, ≥ 1200px |
| `network.jpg` | Sezione "copertura spedizioni" | 4:3, ≥ 1200px |
| `pattern.png` | Texture di sfondo della fascia brand | piccola e ripetibile (tile) |

Il file viene preso automaticamente: nessuna modifica ai template. L'URL
include il timestamp del file, quindi dopo la sostituzione il browser mostra
subito la nuova immagine.

⚠️ Non usare foto dei prodotti del feed sulle pagine pubbliche: sono
indicizzabili e il catalogo deve restare riservato.
